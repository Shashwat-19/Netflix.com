## 📝 Overview

A **pixel-perfect**, fully responsive clone of Netflix's landing page built with pure HTML5 and CSS3. This project demonstrates modern web development techniques, responsive design principles, and advanced CSS animations. It replicates the user interface and user experience of Netflix's homepage, including interactive elements like accordion FAQs and smooth hover effects.

### 🎯 Project Goals

- **UI/UX Replication**: Accurately recreate Netflix's visual design and layout
- **Responsive Design**: Ensure seamless experience across all device sizes
- **Performance**: Optimize for fast loading and smooth interactions
- **Accessibility**: Follow web accessibility best practices
- **Code Quality**: Write clean, maintainable, and well-structured code

## ✨ Features

### 🎨 Design & Layout
- **Pixel-Perfect Design**: Faithful recreation of Netflix's visual identity
- **Responsive Layout**: Optimized for desktop, tablet, and mobile devices
- **Modern Typography**: Uses Poppins font family for clean, readable text
- **Netflix Branding**: Authentic color scheme and visual elements

### 🖥️ Interactive Components
- **Navigation Bar**: Clean header with language selector and sign-in button

## 🚀 Getting Started

### 📋 Prerequisites

- Any modern web browser (Chrome, Firefox, Safari, Edge)
- No additional software or dependencies required!

### 💻 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/Shashwat-19/Netflix.com.git
   ```

2. **Navigate to project directory**
   ```bash
   cd Netflix.com
   ```

3. **Open in browser**
   - **Option 1**: Double-click `index.html` to open in your default browser
   - **Option 2**: Right-click `index.html` → "Open with" → Choose your browser
   - **Option 3**: Use Live Server extension in VS Code for development

### 🌐 Live Server (Recommended for Development)

For the best development experience:

```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (if you have http-server installed)
npx http-server

# Using PHP
php -S localhost:8000
```

Then open `http://localhost:8000` in your browser.

## 📱 Responsive Design

The website is fully responsive and optimized for:

- **🖥️ Desktop**: Full-width layout with side-by-side feature sections
- **📱 Tablet**: Stacked layout with adjusted spacing and font sizes
- **📲 Mobile**: Single-column layout with touch-friendly interfaces

### 🎨 CSS Features Used
- **Flexbox**: For flexible and responsive layouts
- **CSS Grid**: For complex multi-column arrangements
- **Media Queries**: Breakpoints at 768px and 1024px
- **Viewport Units**: For responsive font sizing and spacing
- **Transform**: For smooth hover effects and animations
